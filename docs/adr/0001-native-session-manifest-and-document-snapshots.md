# 桌面会话使用原生清单与分文档快照

桌面版把会话恢复数据保存在 Tauri 应用数据目录：清单记录文档标签顺序、活动文档及工作区元数据，每个文档独立保存内容与已保存基线，文件更新通过临时文件原子发布完成；浏览器版继续使用 `localStorage` 降级。相比单一快照文件，这会增加快照生命周期和清理逻辑，但能增量写入大型工作区、突破浏览器存储上限，并降低一次写入失败损坏整个会话的风险。升级时仅在原生存储为空且存在旧 `localStorage` 会话时自动导入；全部原生文件成功写入后才标记迁移完成，旧数据暂留以支持失败恢复和版本回退。桌面快照不设应用级容量上限，磁盘空间、权限或其他写入错误才视为持久化失败；浏览器降级仍受 `localStorage` 配额限制。每次提交先写入带版本的文档快照，全部成功后再发布新的版本化清单；加载时选择最新的完整清单。异常终止后忽略未提交产物，避免拼接新旧状态，也避开 Windows 对重命名覆盖现有文件的差异。编辑停止 `750ms` 后提交，持续编辑最长每 `5s` 提交一次，窗口失焦和正常退出时立即刷新，以平衡大型文档写入成本与异常恢复的新鲜度。
