# KNOWN_ISSUES —— 标签排序、树操作布局与跨平台 Hot Exit

## [2026-08-11] 浏览器会话仍受 localStorage 配额限制

- 发现于：H5 / 浏览器降级持久化
- 问题描述：原生清单与分文档快照只在 Tauri 桌面版启用，浏览器开发模式仍可能在约 4 MiB 后无法恢复文档。
- 建议：维持现有明确提示；若未来要求浏览器大型会话恢复，单独评估 IndexedDB。
- 状态：已接受，不在本批次范围。

## [2026-08-11] 真正的系统强制终止不能保证最后编辑已提交

- 发现于：H5 / 750ms debounce 与 5s max wait
- 问题描述：系统直接杀进程时应用无法执行退出 flush，持续输入期间最多可能缺少最近一个未完成恢复点。
- 建议：恢复最近一次完整 generation，不读取半成品；不对外宣称强制终止零丢失。
- 状态：已接受。

## [2026-08-11] 标签排序本轮没有键盘替代

- 发现于：H2 / 标签拖拽
- 问题描述：排序只能通过指针拖拽完成，未覆盖非拖拽输入方式。
- 建议：后续增加标签焦点下的左右移动命令与命令面板入口。
- 状态：用户明确暂不需要。

## [2026-08-11] Rust 与 Windows 原生验收未在当前主机执行

- 发现于：H4、H7、H9
- 问题描述：当前主机没有 `cargo`、`rustc` 或 `rustfmt`，也不能真实触发 Windows 标题栏关闭与 `Alt+F4`。
- 建议：在带 Rust 1.77.2+ 的环境运行 `cargo test --manifest-path src-tauri/Cargo.toml` 和
  `cargo check --manifest-path src-tauri/Cargo.toml`；Windows 行为交由 CI 或 Windows 安装包验证。
- 状态：实现与测试用例已完成，平台执行待补。

## [2026-08-11] Playwright 视觉检查按用户指示跳过

- 发现于：H9 / 浏览器视觉 QA
- 问题描述：本轮未执行 1440×900、1024×768、375×812 的明暗主题截图验收。
- 建议：后续 UI 改动前补一次真实浏览器检查；现有组件测试覆盖拖拽落点、取消、边缘滚动和 CSS 收缩规则。
- 状态：用户明确要求跳过。

## [2026-08-11] 旧 localStorage 会话暂不清理

- 发现于：H5 / 升级迁移
- 问题描述：迁移成功后旧 key 仍占用 WebView 存储，但不会再作为原生会话来源。
- 建议：至少跨过一个稳定版本后再增加显式清理迁移，保留版本回退空间。
- 状态：按设计保留。
